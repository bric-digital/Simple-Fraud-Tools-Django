These are data files that can be loaded into the IP address database instances.

**GeoLite2-City.mmdb:** This is the MaxMind [free GeoLite database](https://dev.maxmind.com/geoip/).

**ipv4-vpn.mmdb:** This is a synthetic database assembled from the [X4BNet/lists_vpn](https://github.com/X4BNet/lists_vpn) lists used to identify VPNs, data centers, and everything else.

*These are provided for your convenience - updated databases should be acquired / built, as these are provided as examples, and will **not** be updated regularly.*
